# ひだまりノート（フィットイージー 西浦和店）

スタッフ全員で使う「情報共有ノート」です。スマホでもPCでも使えます。

- **電話メモ・口頭メモ**：電話で聞いたこと、口頭で教わったことをその場で残す
- **引継ぎ・告知**：シフト間の引継ぎ、店長やスタッフからのお知らせ
- **ノウハウ**：マニュアルにない対応や解決法をためていく（検索ですぐ見つかる）
- **相談箱**：スタッフから店長へ解決してほしいこと。**公開／非公開**を選べる（非公開は本人と店長だけが見られる）
- **読んだらチェック**：「読みました。確認しました」ボタンで、誰が読んだか・まだの人が一目でわかる
- **確認表**：スプレッドシートに「要確認のお知らせ × スタッフ」のチェック表が自動で作られる

データはお店の **Googleスプレッドシート** に保存され、サイトは **GitHub Pages** で無料公開します。

## まず試す（設定なし）

`index.html` をダブルクリックで開くと **お試しモード** で動きます。
PIN は 店長：`0000`／スタッフ：`1111`。書いた内容はその端末にだけ保存されます。

## 本番の準備（約15分・店長が1回だけ）

### ① スプレッドシートを用意する

1. Googleドライブで **新しいスプレッドシート** を作る（名前例：ひだまりノート_西浦和店）
2. メニュー **拡張機能 → Apps Script** を開く
3. 最初からある文字を全部消して、`gas/Code.gs` の中身を **全部貼り付けて保存**（💾）
4. 上の関数の選択で **`setup`** を選び **▶ 実行**
   - 「承認が必要です」→ 自分のアカウント → 「詳細」→「（安全ではないページ）に移動」→ 許可
5. スプレッドシートに「投稿／既読／コメント／スタッフ／確認表」のシートができます

### ② スタッフを登録する

「スタッフ」シートに1人1行で入れます。

| 名前 | PIN | 役割（店長/スタッフ） | 退職（チェックで非表示） |
|---|---|---|---|
| 山本 | 4821 | 店長 | ☐ |
| 佐藤 | 1937 | スタッフ | ☐ |

- PIN は一人ずつ別の数字にしてください（非公開の相談を守るため）
- 辞めた人は「退職」にチェックを入れると一覧から消えます（書いた記録は残ります）

### ③ ウェブアプリとして公開する

1. Apps Script の右上 **デプロイ → 新しいデプロイ**
2. 種類の歯車 → **ウェブアプリ**
3. 次のユーザーとして実行：**自分**／アクセスできるユーザー：**全員**
4. **デプロイ** → 表示された **ウェブアプリのURL**（`https://script.google.com/macros/s/…/exec`）をコピー

> ※ Code.gs を後で書き換えたときは「デプロイを管理 → 編集（鉛筆）→ バージョン：新バージョン → デプロイ」でURLはそのまま更新できます。

### ④ GitHub にサイトを置く

1. GitHub にログイン → 右上 **＋ → New repository**
   - 名前例：`hidamari-note`、**Public** を選んで作成
2. **Add file → Upload files** で `index.html` をアップロード（`gas` フォルダや README も一緒でOK）
3. アップした `index.html` を開き、鉛筆マーク（Edit）で編集。上のほうのここを書き換え：

   ```js
   const CONFIG = {
     API_URL: "③でコピーしたURL",
   ```
   → **Commit changes**
4. リポジトリの **Settings → Pages**
   - Source：**Deploy from a branch**、Branch：**main** ／ **/(root)** → Save
5. 1〜2分で `https://（GitHubのユーザー名）.github.io/hidamari-note/` が使えるようになります

### ⑤ スタッフに配る

- URL を店内LINE等で共有し、**スマホのホーム画面に追加** してもらうとアプリのように使えます
  - iPhone：Safari の共有ボタン → ホーム画面に追加
  - Android：Chrome のメニュー → ホーム画面に追加
- 初回だけ名前を選んでPINを入れれば、次から自動でログインします

## 毎日の使い方

| やりたいこと | 操作 |
|---|---|
| 電話・口頭で聞いたことを残す | 右下「書く」→ 電話メモ／口頭メモ |
| 次のシフトに伝える | 「書く」→ 引継ぎ（自動で「要確認」になります） |
| 全員にお知らせ | 「書く」→ 告知（要確認） |
| 店長に相談 | 「相談箱」→ 相談を書く → 公開／非公開を選ぶ |
| 困ったとき | 「ノート」で検索（コメントの中も検索されます） |
| 読んだ | ノートを開いて「読みました。確認しました」 |
| 誰が読んだか見る | 「確認状況」タブ、またはスプレッドシートの「確認表」 |

**店長だけができること**：相談の対応状況（受付→対応中→解決済み）の変更、誰の投稿でも削除。

## 安心して使うために

- サイトのプログラムは GitHub で公開されますが、**投稿の中身はスプレッドシートにだけ** 保存されます。
- 投稿を見るには「名前＋PIN」が必要です。非公開の相談は、サーバー側で本人と店長以外には送られません。
- スプレッドシート自体は **店長だけ** が開ける共有設定のままにしてください。
- 会員様の電話番号など個人情報は、必要最低限にしてください。
- 削除した投稿はスプレッドシートの「削除」列に印がつくだけで、行は残ります（あとから確認できます）。

## 困ったとき

- **「スタッフ名を読み込めません」**：`API_URL` が正しいか、③で「アクセスできるユーザー：全員」になっているか確認。
- **PINを入れても入れない**：「スタッフ」シートの名前・PINに余計な空白がないか確認。
- **確認表が古い**：スプレッドシートのメニュー「ひだまりノート → 確認表を更新」。
